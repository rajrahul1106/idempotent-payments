How it works
  1. You send a payment with a unique request ID.
  2. The bank checks the ID, so a repeat is answered, never charged again.
  3. In one step it takes the money from one account and adds it to the other.
  4. In that same step it saves a delivery note for the follow-up work.
  5. A courier hands the note to a processor, which may receive it more than once.
  6. The processor remembers every note it has done, so the follow-up runs exactly once.
